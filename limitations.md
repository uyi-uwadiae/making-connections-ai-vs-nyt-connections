# Limitations

- One run per model, so a few unlucky guesses can swing a result.
- Models saw the solutions after every round, so later rounds are not independent of earlier ones.
- Custom puzzles are niche and reverse-engineered, so alternative valid solutions are possible.
- No human baseline on the three unpublished custom puzzles.
- Free tiers only, with different reasoning options per model (Grok had none).
- Copilot limited daily responses, so its rounds were spread over more days.
- Some model behavior, such as anchoring on similar past puzzles, comes from reading visible reasoning and is observational.
